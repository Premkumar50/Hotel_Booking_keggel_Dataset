
# 🏨 Hotel Booking Cancellations Dashboard

## 📊 Project Overview

This project focuses on analyzing hotel booking data to understand booking trends, cancellations, guest preferences, and room allocation status.

The dataset was downloaded from Kaggle and analyzed using Microsoft Excel. An interactive dashboard was created to present key insights through charts, graphs, and KPIs.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* Interactive Dashboard
* Data Visualization

## 📁 Project Files

* `Cleaned & Dashboard.xlsx` — Cleaned dataset and interactive dashboard.
* `hotel_booking Row data.csv` — Original raw hotel booking dataset downloaded from Kaggle.
* `Screenshot 2026-10-22 215429.png` — Dashboard screenshot.

## 📈 Dashboard Highlights

The dashboard provides insights into:

* **Total Bookings:** Overall number of hotel bookings.
* **Total Cancellations:** Number of cancelled bookings.
* **Monthly Booking Trends:** Monthly comparison of bookings and cancellations.
* **Bookings by Guest Type:** Analysis of couples, families, and single guests.
* **Bookings by Hotel Type:** Comparison of City Hotels and Resort Hotels.
* **Cancellations by Hotel Type:** Cancellation analysis for different hotel types.
* **Bookings by Room Allocation:** Analysis of desired and undesired room allocation status.
* **Year-wise Analysis:** Interactive year filter to explore booking data across different years.

## 🎯 Project Objectives

* Analyze hotel booking and cancellation trends.
* Compare booking patterns across different guest types.
* Understand differences between City Hotels and Resort Hotels.
* Identify monthly changes in bookings and cancellations.
* Present key business metrics through an interactive Excel dashboard.

## 📊 Key Performance Indicators (KPIs)

* Total Bookings
* Total Cancellations
* Monthly Bookings
* Monthly Cancellations
* Guest Type Distribution
* Hotel Type Distribution
* Room Allocation Status
